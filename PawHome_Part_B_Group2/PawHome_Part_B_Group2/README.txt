PawHome - קבוצה 2
==================
פרויקט הקורס בניית מערכות מבוססות WEB, חלק ב': צד לקוח
מגישות: נוי דדון, נועם ברק, שחר מטלון

הפעלה
-----
1. פותחים את קובץ ה-ZIP.
2. פותחים את הקובץ index.html בדפדפן (Chrome, Edge או Firefox).
אין צורך בהתקנה או בשרת. הגופנים נטענים מ-Google Fonts כשיש חיבור לאינטרנט.

משתמשי הדגמה (מופיעים גם בעמוד ההתחברות עם כפתור "מילוי")
- מאמצת:  adopter@pawhome.co.il  /  Adopt1234
- עמותה:  friends4@pawhome.co.il  /  Paws1234

הנתונים נשמרים ב-localStorage של הדפדפן ומדמים את בסיס הנתונים של חלק ג'.
כדי לחזור לנתונים המקוריים: "איפוס נתוני ההדגמה" בתחתית כל עמוד.

מבנה התיקיות
------------
index.html          דף הבית
login.html          התחברות
signup.html         הרשמה בשני שלבים
dogs.html           חיפוש כלבים (השירות המרכזי)
dog.html            עמוד כלב אחד לכל הכלבים (dog.html?id=...)
my-requests.html    הבקשות שלי (מאמץ)
publisher.html      ניהול המודעות (מפרסם)
dog-form.html       פרסום ועריכת כלב (מפרסם)
profile.html        הפרופיל שלי: עריכת פרטים ושינוי סיסמה
css/style.css       כל העיצוב, כולל התאמה לנייד ואנימציות
js/data.js          נתוני דמה (users, dogs, adoption_requests)
js/match.js         כללי בדיקת ההתאמה
js/api.js           סימולציה של השרת (כל פונקציה = בקשת HTTP עתידית)
js/validation.js    כללי הולידציה והצגת הודעות שגיאה
js/forms.js         שדות שחוזרים בכמה טפסים
js/ui.js            רכיבים משותפים: ניווט לפי סוג משתמש, הודעות, חלון אישור
js/<עמוד>.js        הקוד של כל עמוד
images/             לוגו ותמונות הכלבים

תמונות הכלבים: מאגר התמונות הפתוח של Dog API (Stanford Dogs Dataset), ושתי תמונות של כלבים שלנו.
